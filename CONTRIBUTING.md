# Contributing to WATERLINE

A useful change strengthens a view, clarifies the reflection, or gives someone a better way to test a claim. State which version it changes, what you observed, and what is still unverified.

- Keep the current six-ring design distinct from the dome and rib archives and from mood imagery. Update affected diagrams, simulator labels and the relevant notes together.
- Use original work with confirmed provenance. Do not add private materials, personal information, third-party imagery or derivatives, or references whose redistribution rights are unclear.
- Do not add live control, telemetry, external dependencies or sensors to this repository. The web page and one-way link to the float in v0.5 are described in the notes, not built here. Weather, public choices and audio remain local simulations. Sound must default off. Add a non-audio equivalent.
- Verify keyboard access, a narrow screen, reduced motion, local-file/network-off execution, and accurate status messages. See [manual checks](tests/manual.md).
- No project license is declared here. Public visibility is not permission to assume a license or reuse rights.
