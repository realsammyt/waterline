# Find, offer, open

**Find.** The walking path is the first game: discover a gathered view, see its separated fins, then watch a wake redraw the water. No phone, exact standing spot, boarding, or touch is required.

**Offer.** “Add a Ripple” is an optional short Still / Wake / Return play pattern. On a device, one press changes the local illustration; in a staffed pilot, an approved dry viewing spot could have one seated-reachable tactile button and a local indicator. A quiet printed prompt is equivalent. No competition, scoring, microphone, camera, geolocation, account, or public feed. Do not send people to the rail, block the through-route or assume that first-time offline visitors can load a web page.

**Open.** A short shared event could use a pre-authored 60–90 second cue sheet. The host and optional local web or shore preview share an approximate timing plan. If timing or connectivity fails, use the paper score or self-paced experience. Aggregate shore inputs, if ever used, affect only the local display. An independently armed preloaded ember cue is a separate future review, not a pilot requirement. Do not wire, network or otherwise connect public interfaces to the float, lights or operator controls.

Aim for [WCAG 2.2 AA](https://www.w3.org/WAI/WCAG22/quickref/) where applicable. Verify keyboard, touch, screen-reader and reduced-motion equivalents, route and reach accessibility, and staff ability to halt the optional shoreline program. Audio is opt-in and the visual/text score must work in silence. No visitor-level data is needed; review any future host logs separately. Drop an optional layer if it introduces congestion, an unapproved physical install, or dependence on a network.

The [v0.2 archive preview](../simulators/aperture.html) shows local shore and event cue ideas; it is not a deployed activation.
