# Find, offer, open

**Find.** The walking path is the first game: find where the six rings cross into one eye, walk until the crossings slide apart, then watch a wake redraw the water. No phone, exact standing spot, boarding, or touch is required.

**Offer.** One choice an hour. A printed sign carries a code to a web page that lists the six values in [Six Rings on Mother](rings-on-mother.md), and the visitor picks the one the next hour should hold. The same page opens anywhere in the world. One press: no competition, scoring, microphone, camera, geolocation, account, text or public feed. The sign names the six values and their tones in print, so the band can be read without a phone. Do not send people to the rail, block the through-route or assume that first-time visitors can load a web page. A tactile button at a dry, seated-reachable spot is an option only with approval.

**Open.** A few calendar nights (first and last of the season, the solstice, the full moons) play an authored score stored on the float. A hosted gathering can form around the top of any hour, when the thread passes. The link is one way: once an hour the float fetches a count of choices. No public interface can reach the lights' power, the navigation lights or any operator control. If the link fails, the work plays its authored order and the printed sign still explains it. The web page and the link are proposed, not built.

Aim for [WCAG 2.2 AA](https://www.w3.org/WAI/WCAG22/quickref/) where applicable. Verify keyboard, touch, screen-reader and reduced-motion equivalents, route and reach accessibility, and staff ability to halt the optional shoreline program. Audio is opt-in and the visual/text score must work in silence. No visitor-level data is needed; review any future host logs separately. Drop an optional layer if it introduces congestion, an unapproved physical install, or dependence on a network.

The [v0.2 archive preview](../simulators/aperture.html) shows local shore and event cue ideas for an earlier form; it is not a deployed activation. A printed shore prompt for v0.5 can carry the four words in [Six Rings on Mother](rings-on-mother.md).
